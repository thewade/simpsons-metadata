Make a request

Start with one fetch.

Responses are keyed by IDs such as s01e01. There are no per-record URLs or server-side filters: fetch a dataset and query it locally.

Explore every endpoint in the API reference →
JavaScript example
const episodes = await fetch(
  'https://api.simpsonseh.com/v1/episodes.json'
).then(response => response.json());

console.log(episodes['s01e01'].titles.en);
// Simpsons Roasting on an Open Fire
